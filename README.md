# Simulador de Relatividade

**Schwarzschild Lab — v1.0.0**

Laboratório virtual didático para explorar o desvio gravitacional de frequência na métrica de Schwarzschild.

## Como usar

Abra `index.html` em um navegador moderno. Não é necessária instalação nem conexão com a internet.

## Funcionalidades

- Paraboloide de Flamm interativo, com controle de altura visual e rótulos.
- Parâmetros de massa, coordenadas radiais dos observadores e comprimento de onda.
- Painéis de métrica, ondas, relógios, curva, espectro, geodésica, cenários e fundamentos.
- Modo captura e exportação CSV.

## Modelo físico

Observadores estáticos no exterior do horizonte de eventos. A razão de frequências é dada por `sqrt((1 - Rs/rE)/(1 - Rs/rR))`. O receptor no infinito representa o limite assintótico. O paraboloide representa uma seção espacial; a animação do percurso da luz é esquemática. Não são modelados movimento relativo nem rotação da massa central.
